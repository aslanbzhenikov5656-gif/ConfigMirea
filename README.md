### Типы данных
- **Числа**: `[1-9][0-9]*`
- **Строки**: `q(Это строка)`
- **Массивы**: `<< значение, значение, ... >>`
- **Вложенные массивы**

### Имена
Имена идентификаторов задаются регулярным выражением:

```

[_a-z]+

```

(цифры в именах запрещены)

---

## 🔧 Константы и вычисления

### Объявление констант

```

const имя = значение;

```

### Константные выражения (вычисляются на этапе трансляции)

```

$имя + 1$

```

Поддерживаются операции и функции:
1. Сложение (`+`)
2. Вычитание (`-`)
3. `concat(a, b)`
4. `sqrt(x)`

Результатом вычисления всегда является значение.

## 🧪 Тестирование

Для тестирования используется библиотека **pytest**.

### Запуск всех тестов

```bash
pytest
```

или

```bash
python -m pytest
```

### Запуск отдельного файла тестов

```bash
pytest tests/test_functions.py
```

### Запуск одного теста

```bash
pytest tests/test_functions.py::test_sqrt
```

### Подробный вывод

```bash
pytest -v
```

---

## 🧪 Покрытие тестами

Тесты покрывают **все конструкции языка**, включая их возможную вложенность:

* числа
* строки
* массивы и вложенные массивы
* объявления констант
* вычисления `$expr$`
* операции `+` и `-`
* функции `sqrt()` и `concat()`
* обработку синтаксических и семантических ошибок

Реализованы:

* **unit-тесты** (отдельные конструкции языка)
* **интеграционные тесты** (полные cfg-файлы)
